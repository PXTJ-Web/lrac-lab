# 轻量增强模型验证简报

> 梁鸣轩 ｜ 2026-09-16 ｜ 任务：基于约 10G 规模数据集验证增强效果、分析最差场景、评估覆盖与泛化

---

## 一、任务完成对照

| 老师要求 | 完成情况 |
|---|---|
| 基于约 10G 规模数据集验证 | 官方管线构建 release **28 GB / 50,662 条**（**通过官方 `lrac-data validate` 校验**），并合成 **10,500 条带噪语料**（7 档 SNR）用于验证 |
| 最差场景及原因 | **定位在"输入接近干净"（+25 dB 档）**：12 个最差组合全部落在此档；根因是处理强度不随输入质量自适应 |

| 泛化性能 | 在**未见过的噪声类型**上普遍有效；⚠️ **跨语言未覆盖**（数据仅英语） |

## 二、数据与验证方法

- **数据**：官方数据管线 `lrac-data prepare` 构建 `lrac-10g` edition（vctk 语音 + fsd50k 噪声）。切分符合官方规格：train 45,882 ｜ **validation 350**（250 语音 + 100 噪声）｜ open-evaluation 4,000（官方 2025 公开测试材料）；
- **验证语料**：从 release 取干净语音 + 真实噪声，按 **−5/0/+5/+10/+15/+20/+25 dB** 七档合成 **10,500 条**，每条配干净参考；SNR 精度经复核精确命中；
- **评测**：3 个轻量候选跑全量 10,500 条，2 个基线跑同一 2,100 条子集；指标 SI-SDR（保真）、LSD（谱失真），**逐样本判定**不劣化/有效增强/显著劣化。

## 三、核心结果

**五模型公平对比（同一 2,100 条子集）**

| 模型 | 参数量 | 平均ΔSI-SDR | 不劣化率 | 显著劣化率 |
|---|---|---|---|---|
| SepFormer | 25.61 M | **+9.74** | 97% | 1% |
| **UL-UNAS** | **171.3 K** | **+7.99** | 92% | 3% |
| **GTCRN** | **48.2 K** | +6.87 | 91% | 3% |
| LiSenNet* | 37 K | −1.01 | 44% | 21% |
| MetricGAN+ | 1.90 M | −2.78 | 40% | **45%** |

\* 社区重训权重（官方未发布）。**UL-UNAS 用 1/150 参数拿到 SepFormer 82% 的增益；GTCRN 用 1/531 参数拿到 71%。**

**按输入 SNR 分层（全量 10,500 条）**

|---|---|---|---|
| −5 dB | **+14.73** | +12.99 | +1.64 |
| 0 dB | **+12.84** | +11.34 | +1.22 |
| +5 dB | **+10.49** | +9.17 | +0.70 |
| +10 dB | **+8.23** | +7.20 | −0.11 |
| +15 dB | **+5.80** | +4.88 | −1.31 |

## 四、最差场景与原因（核心结论）

1. **最差场景 = 输入已接近干净（SNR ≥ 20–25 dB）**，不是某类难噪声：**12 个最差组合全部在 +25 dB 档**，与噪声类型相关性很弱；
2. **根因：处理强度不随输入质量自适应**——输入越干净，模型仍按固定强度抑制，把有用信号一起削弱；**谱失真由改善转为恶化**（UL-UNAS 的 ΔLSD 从 −9.58 dB 升到 +1.31 dB）；
3. **临界点在 20–25 dB 之间**，恰好与官方 Track 1 轻噪声条件的 SNR 区间（10–25 dB）交叠 → **该问题在比赛数据上真实存在**；
4. **可落地改进**：加**输入质量门控**（>20 dB 时减弱/旁路增强），预计救回全量语料中约 **12–14% 的劣化样本**。

## 五、结论

1. **前端选型：UL-UNAS 优先、GTCRN 作参数效率备选**（UL-UNAS 在每一档 SNR 都优于 GTCRN，且自带零前瞻流式 + ONNX 导出；GTCRN 以 28% 的参数达到其约 86% 效果）；
2. **必须修高 SNR 档的过度处理**（唯一净负收益场景）；
3. **LiSenNet 须复现官方训练**（社区权重不可用；全量平均 −1.12 dB，各档 ΔLSD 均为正）；
4. **继续堆参数无意义**：25.6 M 的 SepFormer 只比 171 K 的 UL-UNAS 高 18% → 资源应投向"适配与门控"。
